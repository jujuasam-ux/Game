# 💕 Steven & Julia's Date Night App 💕

A fun, interactive web app for long-distance couples to play games and have memorable date nights together!

## Features

### 🎮 Games Included:

1. **Would You Rather** - Choose between fun scenarios and debate your picks!
2. **Question Jar** - Deep, fun, and romantic questions to get to know each other better
3. **Truth or Dare** - Classic game with a couples twist
4. **Date Night Spinner** - Spin the wheel and get random date ideas
5. **Couples Trivia** - Test how well you know each other
6. **20 Questions** - One person thinks of something, the other has 20 questions to guess!

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm

### Installation

1. Clone the repository
```bash
git clone <repo-url>
cd Game
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```

4. Open your browser and go to `http://localhost:3000`

## How to Play

1. Click on any game from the main menu
2. Follow the on-screen instructions
3. Have fun together!
4. Click "Back to Games" to return to the menu

## Technology Stack

- React 18
- Vite (build tool)
- Lucide React (icons)
- CSS3 (with gradients and animations)

## Tips for Best Experience

- 📱 Use on desktop or tablet for best experience
- 📞 Play over video call to see each other's reactions!
- 💬 Take time to really listen to each other's answers
- 🎉 Enjoy the laughs and create memories together
- 📸 Screenshot your favorite moments

## Building for Production

```bash
npm run build
```

The compiled files will be in the `dist/` folder.

## Customization

Feel free to modify the questions and date ideas to make the app more personal to you! Edit the arrays in each game component.
